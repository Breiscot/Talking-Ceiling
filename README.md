## Description
Talking Ceiling is a 3D survival game where you have to care for a seal in a snowy environment. Gather resources, keep the fire burning, and complete 15 levels of increasing difficulty.

The game supports both `Desktop` mode and `Virtual Reality (VR)` with OpenXR compatible controllers.
> `Virtual Reality (VR)` mode is PARTIALLY APPLIED, not verified as working as there has been no further development

## Features

- Survival gameplay with resource management
- 15 levels with progressive difficulty
- Dynamic day/night cycle
- Fire system fueled by wood
- Partially VR mode
- Two difficulty settings: Easy and Hard
- Settings (audio, mouse sensitivity, fullscreen)

## Desktop Controls

| Key | Action |
|-------|--------|
| WASD | Move |
| Mouse | Look around |
| Space | Jump |
| Shift | Run |
| E | Interact (pick up, feed, give wood) |
| F | Talk to the seal |
| ESC | Pause menu |
